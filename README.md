# LacostShop ⭐

Стартовый проект Telegram-магазина с чёрно-золотым брендингом, каталогом,
SQLite-заказами и оплатой Telegram Stars (XTR).

## Важно до запуска

1. Токен, который вы ранее отправили в чат, считать скомпрометированным.
   Отзовите его через @BotFather командой `/revoke` и используйте только новый.
2. Не вставляйте токен в исходный код. Храните его в `.env`.
3. Для продажи цифровых товаров внутри Telegram используйте Telegram Stars (XTR).
   Внешние способы оплаты (карты/СБП/криптовалюта) нельзя просто подключить
   вместо XTR внутри такого бота.
4. Telegram Bot API не умеет самостоятельно зачислять Stars на баланс другого
   пользователя. Для автоматической выдачи нужен поставщик с документированным API.
5. В `bot.py` цены в рублях сохранены как согласовано, но демонстрационная
   конвертация в XTR сделана 1:1 только как заглушка. Это НЕ курс и НЕ готовый прайс
   для публикации. Установите корректные XTR-цены перед приёмом реальных платежей.

## Установка

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`, заполните:
- `BOT_TOKEN` — новый токен от @BotFather
- `ADMIN_ID` — ваш числовой Telegram ID

Запуск:

```bash
python bot.py
```

## Что уже работает

- `/start` и меню LacostShop
- каталог 50 / 100 / 250 / 500 / 1000 / 2500 / 5000 Stars
- создание заказа и запись в SQLite
- invoice в валюте XTR
- список заказов пользователя
- уведомление администратору, если поставщик не подключён

## Что ещё нужно подключить

- API поставщика и проверку результата выдачи в `supplier.py`
- сохранение Telegram username/суммы в заказе и обработку повторных webhook/callback
- административные команды и редактирование каталога
- корректные цены XTR и тексты поддержки
- сервер/хостинг и резервные копии БД

Не принимайте реальные оплаты до завершения этих пунктов и тестирования.
